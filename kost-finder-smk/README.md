# Kost-Finder (UKK PPLG 2026/2027)
Aplikasi pencarian & pemesanan kos berbasis peta.

- `frontend/` → React + Vite + Vanilla CSS (tahap 1: data dummy)
- `backend/auth-service/` → Express (login, OTP, lupa password) — tahap 2
- `backend/content-service/` → Express (kos, kamar, booking, review, upload Cloudinary) — tahap 3

## Menjalankan frontend
```
cd frontend
npm install
npm run dev
```
